# Distribute with Developer ID, unsandboxed, under GPLv3

Swiftpolis ships outside the Mac App Store, notarized with Developer ID, with the main app unsandboxed and licensed GPLv3. A port of Persepolis is likely a derivative work of GPLv3 code, and the App Sandbox conflicts with shutting down the Mac, saving to any folder and updating yt-dlp. The Safari extension itself remains sandboxed, as Apple requires.
